# مصادر البيانات الطبية

## الاختيار

يعتمد الإصدار الحالي على فهرس SQLite محلي صغير لعلاقات الأعراض والموضوعات، مع روابط مصدر ظاهرة للمستخدم. مصدر المحتوى التثقيفي الأساسي هو **MedlinePlus** التابع للمكتبة الوطنية الأمريكية للطب؛ توفر MedlinePlus خدمة بحث XML وملفات XML كاملة لموضوعات الصحة، وتذكر أن الخدمة تُحدّث يومياً من الثلاثاء إلى السبت، مع طلب نسب المصدر وعدم استخدام الشعار أو الإيحاء بالتأييد [1].

يُحفظ أيضاً وصف مصدر **Disease Ontology** ضمن جدول المصادر بوصفه طبقة مصطلحات مرضية مفتوحة بترخيص CC0 1.0، مع رابط الإصدار الشهري وملف التنزيل الرسمي. لا تُستخدم هذه الطبقة وحدها لإنشاء علاقة عرض-مرض؛ فهي مرجع للمصطلحات وتصنيف الأمراض، بينما تبقى روابط التثقيف والملخصات للمستخدم من MedlinePlus [2].

## البنية

| الجدول | الغرض |
| --- | --- |
| `medical_sources` | اسم المصدر، الرابط، الترخيص، وملاحظة التحديث. |
| `medical_symptoms` | معرف العرض، تسمياته بالعربية والفرنسية والإنجليزية، والمرادفات. |
| `medical_conditions` | أسماء الحالات باللغات الثلاث ورابط MedlinePlus لكل حالة. |
| `condition_symptoms` | الربط بين الحالة والأعراض المستخدمة في ترتيب المطابقة. |
| `source_cache` | تخزين نتائج بحث MedlinePlus لمدة 24 ساعة لتقليل الطلبات. |
| `checks` | إحصاءات مجهولة عن عدد المطابقات ونوع الخطر واللغة، دون حفظ الأعراض. |

## التحديث

تُزامن الجداول المحلية تلقائياً عند تشغيل الخلفية. لتحديث ذاكرة MedlinePlus المؤقتة يدوياً:

```bash
python3 -m backend.update_medical
```

تستخدم المهمة استعلامات محدودة للحالات المفهرسة وتحتفظ بالنتائج 24 ساعة. هذا يلتزم بتوصية MedlinePlus بالتخزين المؤقت وعدم تجاوز 85 طلباً في الدقيقة لكل عنوان IP [1].

## حدود الاستخدام

العلاقات الحالية فهرس تعليمي صغير وليست قاعدة قرار سريري أو مجموعة بيانات تشخيصية معتمدة. ترتيب النتائج يستخدم تغطية الأعراض مع أولوية توجيهية للحالات الشائعة، ولا يعرض احتمالاً إحصائياً أو نسبة دقة. إشارات الطوارئ تعمل في طبقة مستقلة وتسبق النتائج العامة.
